# 2.5 Crypto Audit
Este script analiza transacciones y corrige errores comunes en auditorías cripto.

Esta tarea consiste en:

1. **Sanear las conversiones**: Corregir la acumulación en `saldoTotal`.
2. **Control de Flujo Avanzado**: Aplicar correctamente `continue` y `break` para corregir problemas.
3. **Corregir el desbordamiento**: Identificar que el bucle usa `i <= transacciones.length` y ajustar según corresponda.
